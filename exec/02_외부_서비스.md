# 02. 외부 서비스

## 1. 서비스 목록

| 서비스 | 사용 목적 | 인증·설정 위치 |
|---|---|---|
| GitLab | 소스 코드와 Merge Request | SSAFY GitLab 프로젝트 |
| Jenkins | Backend CI/CD | Jenkins Credentials + `Jenkinsfile` |
| AWS EC2 | Nginx·Spring Boot·Redis 운영 | EC2 IAM Instance Profile |
| AWS RDS PostgreSQL | 영구 관계형 데이터 | Parameter Store·운영 `.env` |
| AWS S3 | 게시글 이미지·영상 | EC2 IAM Role, 비공개 버킷 |
| AWS ECR | Backend Docker 이미지 | Jenkins AWS 자격증명, EC2 IAM Role |
| AWS SSM | SSH 없는 운영 배포·포트포워딩 | EC2 Role + Jenkins IAM |
| AWS Route 53 | `familink360.com` DNS | 개인 AWS 계정 |
| AWS CloudWatch | 로그·메트릭·알람 | EC2 Role·Compose awslogs |
| Firebase Cloud Messaging | Android 푸시 알림 | Firebase 서비스 계정 + `google-services.json` |
| OpenAI Realtime API | 실시간 AI 음성 통화·전사 | `OPENAI_API_KEY` |
| SSAFY GMS | Gemini 텍스트 분석 경로 | `GMS_API_KEY` |
| Google Gemini API | 게시글 미디어·리포트 분석 | `GEMINI_API_KEY` |
| Let's Encrypt Certbot | API HTTPS 인증서 | 운영 EC2의 인증서 디렉터리 |
| Mattermost | Jenkins 배포 결과 알림 | Jenkins Webhook Credential |

소셜 로그인, 이메일 인증, 결제 서비스는 사용하지 않는다.

## 2. AWS

### 2.1 계정과 리전

- 운영 리전: `ap-northeast-2`(서울)
- 운영 리소스: 개인 AWS 계정
- Jenkins·스테이징: SSAFY 제공 EC2
- 태그: `Project=Familink`, `Environment=prod`

### 2.2 핵심 리소스

| 리소스 | 이름·설정 |
|---|---|
| VPC | `familink-prod-vpc`, `10.0.0.0/16` |
| EC2 | `familink-prod-server`, Ubuntu 24.04, `t3.medium`, gp3 50GB |
| RDS | `familink-prod-db`, PostgreSQL 16, `db.t4g.micro`, gp3 20GB, Private |
| S3 | `s15p11b104-media-580779787807-ap-northeast-2-an`, Public access 차단 |
| ECR | `familink-backend`, Git Commit SHA 이미지 태그 |
| 도메인 | `familink360.com`, API `api.familink360.com` |
| EC2 Role | `familink-prod-ec2-role` |

네트워크 흐름:

```text
Internet 80/443 → EC2 Nginx → Backend 8080
EC2 Security Group → RDS Security Group 5432
Backend → Redis 6379 (Docker 내부 네트워크)
Backend → S3·OpenAI·GMS·Gemini·Firebase (HTTPS)
```

`8080`, `6379`, `5432`, SSH `22`는 인터넷에 공개하지 않는다. 운영 접속은
Systems Manager Session Manager를 사용한다.

### 2.3 AWS 권한

운영 EC2 Role에는 다음 최소 권한이 필요하다.

- S3 `post-media/*` 읽기·쓰기·삭제
- ECR 이미지 Pull
- SSM Managed Instance
- Parameter Store `/familink/prod/*` 조회
- CloudWatch Logs·Metric 기록

정책 예시는 다음 파일에 있다.

```text
infrastructure/aws-foundation/iam/ec2-instance-policy.json
infrastructure/ci/jenkins-deploy-policy.json
```

운영 Backend는 `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`를 사용하지 않고
EC2 IAM Role로 S3에 접근한다.

### 2.4 Parameter Store

`/familink/prod/` 계층으로 생성한다. 최소 항목:

```text
/familink/prod/DB_HOST
/familink/prod/DB_PORT
/familink/prod/DB_NAME
/familink/prod/DB_USERNAME
/familink/prod/DB_PASSWORD
/familink/prod/S3_BUCKET
/familink/prod/AWS_REGION
/familink/prod/S3_PRESIGNED_URL_DURATION
/familink/prod/S3_DOWNLOAD_URL_DURATION
```

사용자명·비밀번호·API 키는 `SecureString`으로 관리한다.

## 3. Firebase Cloud Messaging

1. Firebase Console에서 Android 앱을 등록한다.
2. Android package name은 `com.s15p11b104app`으로 설정한다.
3. 클라이언트 설정 파일을 `frontend/android/app/google-services.json`에 둔다.
4. 서버 발송용 서비스 계정 JSON을 생성한다.
5. JSON은 Git 밖의 운영 EC2 경로에 둔다.
6. `FIREBASE_CREDENTIALS_FILE`로 호스트 경로를 지정한다.
7. Compose가 컨테이너의 `/run/secrets/firebase-service-account.json`에 읽기 전용
   마운트하고 `GOOGLE_APPLICATION_CREDENTIALS`로 전달한다.
8. 운영은 `PUSH_ENABLED=true`, 로컬에서 알림이 필요 없으면 `false`를 사용한다.

`google-services.json`의 Firebase 프로젝트 식별값과 서버 서비스 계정 비밀키는
서로 다른 용도다. 서비스 계정 JSON 원문은 절대 커밋하지 않는다.

## 4. OpenAI Realtime API

사용 목적:

- 피보호자의 실시간 음성 AI 통화
- 한국어 음성 입력 전사
- WebRTC 및 서버 Sideband 연결

필수 준비:

1. OpenAI Platform에서 API 프로젝트와 API Key를 생성한다.
2. Realtime API와 사용할 모델에 접근 가능한지 확인한다.
3. 운영 서버에 `OPENAI_API_KEY`를 비밀값으로 주입한다.
4. 방화벽에서 `api.openai.com` HTTPS·WSS 연결을 허용한다.

운영 설정:

```dotenv
OPENAI_REALTIME_MODEL=gpt-realtime-2
OPENAI_REALTIME_TRANSCRIPTION_MODEL=gpt-transcribe
OPENAI_REALTIME_TRANSCRIPTION_LANGUAGE=ko
OPENAI_REALTIME_BASE_URL=https://api.openai.com
OPENAI_REALTIME_SIDEBAND_URL=wss://api.openai.com/v1/realtime
```

API Key는 Android 앱이나 JavaScript 번들에 넣지 않고 Backend에서만 사용한다.

## 5. Gemini와 SSAFY GMS

사용 목적:

- 게시글 사진·본문 분석
- 건별 AI 통화 리포트 생성
- 일일 리포트 생성

텍스트 분석의 SSAFY GMS 경로와 미디어 분석의 Google Gemini 직접 호출 경로를
구분한다.

```dotenv
GMS_API_KEY=<SSAFY_GMS_KEY>
GMS_API_BASE_URL=https://gms.ssafy.io/gmsapi/generativelanguage.googleapis.com

GEMINI_DIRECT_MEDIA_ENABLED=true
GEMINI_API_KEY=<GOOGLE_GEMINI_KEY>
GEMINI_API_BASE_URL=https://generativelanguage.googleapis.com
GEMINI_TEXT_MODEL=gemini-2.5-flash-lite
GEMINI_MULTIMODAL_MODEL=gemini-3.5-flash
GEMINI_CALL_REPORT_MODEL=gemini-3.5-flash
GEMINI_DAILY_REPORT_MODEL=gemini-3.5-flash
```

Google AI Studio 또는 해당 Google Cloud 프로젝트에서 API Key를 발급하고 사용량·쿼터를
확인한다. SSAFY GMS Key는 SSAFY가 안내한 발급 절차와 허용 모델을 따른다.

## 6. Jenkins·GitLab·ECR·SSM

Jenkins에 다음 Credential ID를 정확히 등록한다.

| ID | 종류 | 내용 |
|---|---|---|
| `familink-gitlab-token` | Secret text | GitLab Personal Access Token |
| `familink-aws-ecr` | Username with password | Jenkins 전용 AWS Access Key / Secret Key |
| `familink-prod-instance-id` | Secret text | 운영 EC2 Instance ID |
| `familink-staging-env` | Secret file | 스테이징 전용 `.env` |
| `familink-mattermost-webhook` | Secret text | Mattermost Incoming Webhook |

필수 Jenkins 플러그인:

- Pipeline
- GitLab
- GitLab Branch Source
- Credentials Binding
- Mattermost Notification

GitLab 저장소의 Push와 Merge Request Webhook을 Jenkins Multibranch Pipeline에
연결하고 Script Path를 `Jenkinsfile`로 설정한다.

## 7. Route 53·Nginx·Certbot

1. Route 53에서 `api.familink360.com` A 레코드를 EC2 Elastic IP에 연결한다.
2. Nginx 80을 먼저 실행한다.
3. `/.well-known/acme-challenge/`가 Spring Security를 거치지 않는지 확인한다.
4. Certbot으로 인증서를 발급한다.
5. `infrastructure/production/nginx/conf.d/api-https.conf.example`을 기준으로 HTTPS를
   적용한다.
6. HTTP가 HTTPS로 리다이렉트되는지 확인한다.
7. `certbot renew --dry-run`으로 자동 갱신을 검증한다.

## 8. CloudWatch와 Mattermost

CloudWatch 로그 그룹:

```text
/familink/prod/backend
/familink/prod/nginx
/familink/prod/deploy
```

CloudWatch Agent는 CPU, 메모리, 디스크, 네트워크와 Redis 프로세스를 수집한다.
systemd timer는 1분마다 Backend·Redis health metric을 기록한다. Jenkins는 배포
시작·성공·실패·rollback 결과를 Mattermost로 알린다.

## 9. 비밀정보 전달 체크리스트

다음 값은 GitLab `exec`에 원문을 넣지 않고 팀의 비밀정보 전달 채널로 인계한다.

- AWS Console 또는 IAM 접근 방법
- RDS 사용자명·비밀번호
- Redis 비밀번호
- JWT Secret
- OpenAI API Key
- SSAFY GMS API Key
- Gemini API Key
- Firebase 서비스 계정 JSON
- Jenkins Credentials 원문
- Android release keystore와 비밀번호

인계받은 사람은 값을 `infrastructure/production/.env.example`의 같은 이름 변수에
대응시킨다.
