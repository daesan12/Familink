# 04. 시연 시나리오

## 1. 목표

- 시연 시간: 약 4분
- 등장인물: 보호자 김민수, 피보호자 김영희
- 핵심 메시지: **AI가 가족을 대신하는 것이 아니라, 가족이 다시 대화를 시작하도록 연결한다.**

민수가 손녀 지우의 생일 미역국 사진을 가족 피드에 올리고, 영희는 게시물을 본 뒤
AI와 통화한다. AI는 게시글과 공유 일정을 바탕으로 대화하고, 통화 후 민수는 리포트를
통해 영희의 마음을 확인한 뒤 직접 연락할 계기를 얻는다.

## 2. 인물과 그룹

```text
김영희(72세, 피보호자)
  └─ 외아들 김민수(44세, 보호자) ─ 배우자 박소연(42세)
                                  └─ 딸 김지우(9세)
```

그룹:

- `영희네 가족`: 김민수(관리자·보호자), 김영희(피보호자), 박소연(보호자)
- `소연이네 가족`: 박소연 측 가족 그룹, 김민수도 보호자로 참여

시연은 민수의 `소연이네 가족` 피드에서 시작해 `영희네 가족`으로 전환한다.

## 3. 시연 계정

| 역할 | 이름 | 로그인 ID | 비밀번호 |
|---|---|---|---|
| 보호자 | 김민수 | `demominsu810` | `Demo12345` |
| 피보호자 | 김영희 | `demoyounghee810` | `Demo12345` |

박소연과 지우 계정은 DB의 가족 구성원 데이터에는 있지만 발표 로그인에 사용하지 않는다.
위 비밀번호는 운영 관리자 비밀번호와 무관한 시연 전용 값이다.

## 4. 사전 데이터

### 4.1 라이브 작성 게시글

- 작성자: 김민수
- 그룹: `영희네 가족`
- 사진: `exec/demo-assets/게시글 작성할사진.jpg`
- 본문:

```text
오늘 지우 생일이라 엄마가 알려준 레시피로 미역국을 끓였어요.
지우가 “할머니가 해준 맛이랑 똑같다”고 했어요 😊
```

라이브 작성 후 게시글 AI 분석이 완료됐는지 확인하고 다음 장면으로 넘어간다. 피드를
자연스럽게 보이게 하는 기존 게시글과 댓글은 `demo-assets/feed-episodes/`를 참고한다.

### 4.2 미리 생성할 일정

| 일정 | 시각 | 참여자 | 설명 |
|---|---|---|---|
| 지우 생일 축하 영상통화 | 2026-08-10 오후 7시 | 민수, 영희 | 지우의 생일을 축하하는 가족 영상통화 |
| 전주 어머니 댁 방문 | 2026-08-15, 종일 | 가족 | 함께 점심을 먹기 위한 주말 방문 |

발표 날짜가 달라지면 AI가 자연스럽게 `오늘 오후 7시`라고 읽도록 영상통화 날짜를
발표 당일로 바꾼다. 현재 DB에는 영상통화가 2026-08-10 오후 7시,
전주 방문이 2026-08-15 종일 일정으로 저장되어 있다.

### 4.3 예상 건별 리포트

통화 요약:

> 지우의 생일을 맞아 민수가 준비한 미역국 이야기를 나누며 기쁜 마음을 표현했습니다.
> 가족 일정을 확인한 뒤, 오늘 오후 7시 지우 생일 축하 영상통화를 기대했습니다.

전달하신 말씀:

> 민수가 지우의 생일 미역국을 준비한 소식을 확인했으며,
> 오늘 오후 7시 가족 영상통화를 기다리고 있다고 전했습니다.

건별 리포트 화면의 통화 시간은 실제 통화 시작·종료 시각을 사용한다.

## 5. 발표 직전 준비

### 민수 화면

- `demominsu810` 로그인 완료
- 현재 그룹 `소연이네 가족`
- 피드 첫 화면
- 지우 생일상 사진을 민수 휴대전화 갤러리 첫 화면에서 바로 선택 가능하게 준비

### 영희 화면

- `demoyounghee810` 로그인 완료
- 현재 그룹 `영희네 가족`
- 피드에서 새 게시글을 새로고침할 수 있는 상태
- AI 전화에서 `사랑스러운 아들` 페르소나 선택 경로 확인

### 서버·네트워크

```text
https://api.familink360.com/actuator/health → UP
Backend·Redis·Nginx container → healthy/running
OpenAI·GMS·Gemini 키와 쿼터 → 정상
두 기기의 Wi-Fi 또는 발표용 핫스팟 → 연결 확인
```

- 불필요한 알림과 자동 화면 꺼짐을 끈다.
- 민수·영희 휴대전화 2대를 각각 미러링하고 `보호자 민수`, `피보호자 영희`
  라벨을 표시한다.
- 기존 활성 AI 통화 세션이 없는지 확인한다.
- 기존 최신 건별 리포트와 새 리포트를 시간으로 구분할 수 있게 확인한다.
- 리허설 후 시연용 데이터 초기화가 필요하면 팀이 합의한 SQL만 사용한다.

## 7. 상세 동작과 대사

### 장면 1. 가족 그룹 전환

민수 동작:

1. 상단의 현재 그룹명 `소연이네 가족`을 누른다.
2. 그룹 목록에서 `영희네 가족`을 선택한다.
3. 피드가 바뀐 것을 1초 정도 보여준다.

민수 대사:

> “장모님 근황도 확인했으니, 이제 어머니가 계신 가족 그룹에 소식을 전하러 가볼게요.”

### 장면 2. 생일 게시글 작성

민수 동작:

1. 게시글 작성 버튼을 누른다.
2. `게시글 작성할사진.jpg`를 선택한다.
3. 준비한 본문을 붙여 넣거나 짧게 입력한다.
4. 등록 버튼을 한 번만 누른다.
5. 게시글이 피드 최상단에 표시되는지 확인한다.

민수 대사:

> “오늘은 딸 지우의 생일입니다. 출근하기 전에 어머니께 배운 레시피로 미역국을
> 끓였는데요. 지금 근무 중이라 직접 전화드리기 전에 먼저 가족 피드로 소식을
> 전해보겠습니다.”

### 장면 3. 공유 일정 확인

민수 동작:

1. 캘린더 탭을 누른다.
2. `지우 생일 축하 영상통화` 일정을 연다.
3. 오늘 오후 7시와 참여자를 보여준다.
4. 같은 주의 `주말 어머니 댁 방문`도 짧게 보여준다.

민수 대사:

> “이번 주 가족 일정도 볼 수 있습니다. 오늘 퇴근한 뒤 오후 7시에 어머니와 지우가
> 생일 축하 영상통화를 하기로 했고, 주말에는 직접 어머니를 찾아뵐 예정입니다.”

### 장면 4. 영희의 피드 반응

영희 동작:

1. 피드를 새로고침한다.
2. 미역국 게시글을 확인한다.
3. 하트 반응을 누른다.
4. AI 전화 탭에서 `사랑스러운 아들`을 선택하고 통화를 시작한다.

영희 대사:

> “어머, 민수가 내가 알려준 대로 미역국을 끓였네. 지우가 잘 먹었나 궁금하다.”

### 장면 5. AI 전화

AI 응답은 실시간으로 달라질 수 있으므로 영희는 아래 네 문장의 의미를 유지하되,
AI 답변이 끝난 뒤 천천히 말한다.

1. `안녕, 아들.`
2. `오늘 기분 너무 좋아. 민수가 지우 생일 미역국을 끓였더라고? 너도 봤어?`
3. `어머, 정말? 혹시 이번 주에 가족 일정 잡힌 거 있을까? 있는 거 다 말해줘.`
4. `곧 만나겠네. 너무 기대된다. 그래, 오늘 대화 즐거웠고 다음에 또 대화하자.`

AI가 게시글을 바로 언급하지 않으면 두 번째 문장에서 반드시 `민수가 올린 미역국
게시글`과 `너도 봤어?`를 포함한다. 일정 답변에서는 오늘 오후 7시 영상통화와 주말
방문 일정이 모두 나왔는지 확인한다. 마지막 AI 답변이 끝난 뒤 종료 버튼을 누른다.

### 장면 6. 건별 리포트 확인

민수 동작:

1. 새 리포트 알림을 누르거나 AI 리포트 탭으로 이동한다.
2. 가장 최신 건별 리포트를 연다.
3. 실제 통화 시각과 통화 요약을 보여준다.
4. `전달하신 말씀`에서 2초 멈춘다.

민수 대사:

> “어머니도 오늘 영상통화를 기다리고 계셨네요. 엄마, 오늘 퇴근하고 지우와 함께
> 연락드릴게요. 이따 영상통화에서 만나요.”

### 장면 7. 마무리

발표자 대사:

> “AI가 가족을 대신한 것이 아닙니다. 민수의 게시글이 영희의 대화가 되고,
> 영희의 마음은 다시 민수의 연락으로 이어졌습니다. 패밀링크는 가족이 다시 대화를
> 시작할 수 있도록 연결합니다.”

## 8. 돌발 상황 대응

| 상황 | 즉시 대응 |
|---|---|
| 게시글 등록이 느림 | 등록 버튼을 다시 누르지 말고 최대 5초 기다린 뒤 피드를 한 번 새로고침 |
| 사진 업로드 실패 | 본문만 등록하거나 사전 게시글을 열어 같은 이야기로 진행 |
| 게시글 AI 분석 지연 | 영희가 게시글 내용을 직접 질문하고, 사전에 생성한 분석 완료 게시글을 백업으로 사용 |
| AI가 미역국을 언급하지 않음 | `민수가 올린 미역국 게시글 너도 봤어?`라고 명시적으로 재질문 |
| AI가 일정 하나만 말함 | `이번 주 다른 가족 일정도 있어?`라고 한 번만 추가 질문 |
| 통화 연결 실패 | 한 번만 재시도하고 실패하면 준비한 리허설 영상 또는 캡처로 리포트 장면 진행 |
| 리포트 알림 지연 | AI 리포트 탭을 직접 열고 최신 목록을 한 번 새로고침 |
| 최신 리포트가 구분되지 않음 | 실제 통화 시각과 가장 최신 생성 시각으로 선택 |
| 네트워크 불안정 | 발표용 핫스팟으로 전환하고 두 기기의 API health를 다시 확인 |

## 9. 최종 리허설 체크리스트

- [ ] 민수·영희 계정 로그인이 각각 정상이다.
- [ ] 민수에게 두 가족 그룹이 모두 보인다.
- [ ] 영희는 `영희네 가족` 피드를 볼 수 있다.
- [ ] 지우 생일상 사진이 기기 갤러리 첫 화면에 있다.
- [ ] 오늘 오후 7시 영상통화 일정과 주말 방문 일정이 보인다.
- [ ] 게시글 등록 후 피드 최상단과 AI 분석 완료를 확인했다.
- [ ] 영희가 하트 반응을 남길 수 있다.
- [ ] AI 전화 마이크·스피커·자막이 정상이다.
- [ ] AI가 게시글과 이번 주 일정을 읽어온다.
- [ ] 통화 종료 후 실제 통화 시각의 새 리포트가 생성된다.
- [ ] 통화 요약과 전달하신 말씀이 예상 문구로 보인다.
- [ ] 전체 흐름을 4분 안에 한 번 이상 완료했다.
- [ ] 백업 네트워크와 백업 리포트 화면을 준비했다.
