# AI 전화 페르소나 선택 화면의 소개글 전용 표시

- 상태: 적용
- 제안자: unknown
- 작성일: 2026-08-03
- 차단 변경: 아니오
- 영향 스펙·계약: `AI_CALL`
- 관련 작업: `S15P11B104-264`

## 기존 내용

[`docs/specs/domains/AI_CALL.md`](../../specs/domains/AI_CALL.md)의 `확정된 동작` 1은
피보호자가 AI 전화 탭에서 페르소나를 선택하고 **예시 발화를 확인한 뒤** 통화를
시작하도록 정의한다.

현재 Android 네이티브 선택 화면도
[`AiCallModels.kt`](../../../frontend/android/app/src/main/java/com/s15p11b104app/aicall/AiCallModels.kt)의
각 `AiPersona`에 `exampleUtterance`를 두고,
[`AiCallContent.kt`](../../../frontend/android/app/src/main/java/com/s15p11b104app/aicall/AiCallContent.kt)에서
선택된 페르소나의 예시 발화를 화면에 표시한다.

## 제안 내용

- AI 전화 페르소나 선택 화면은 선택된 페르소나의 표시명, 소개글과 말투 태그를
  제공하며, 사용자 화면에 텍스트 예시 발화를 필수로 표시하지 않는다.
- 피보호자는 페르소나 소개를 확인하고 원하는 페르소나를 선택한 뒤 통화를
  시작한다.
- 페르소나별 음성 미리 듣기 기능은 추가하지 않는다.
- 이 변경은 사용자 화면의 표시 정보에만 적용한다. Spring Boot 시스템 프롬프트의
  `Sample Phrases`와 예시 발화를 말투 참고용으로 사용하는 규칙은 유지한다.
- 고정 `persona_id` 1~6, 표시명, OpenAI 음성, 호칭, 관계형 말투, 사투리와
  정체성 경계는 변경하지 않는다.

## 변경 근거

- 2026-08-03 사용자 결정: AI 전화 페르소나 선택 화면에서 예시 문장을 제거하고
  페르소나 소개글만 표시한다.
- 사용자 검토용 시안에서 예시 문구가 페르소나 소개와 정보가 중복되고 선택 화면을
  복잡하게 만든다는 피드백이 확인되었다.
- 예시 발화는 통화 세션 생성 요청이나 Realtime 연결 계약에 포함되지 않는 로컬
  표시 데이터이므로, 화면에서 제거해도 `persona_id` 기반 통화 시작 계약은
  유지된다.

## 확인된 영향

- 영향 도메인: `AI_CALL`의 페르소나 선택 단계
- 영향 계약: 없음. `API-CALLS-001`~`API-CALLS-003`과 데이터 모델은 변경하지 않는다.
- 영향 화면: 피보호자 `AI 전화` 탭의 페르소나 선택 화면(`F-1`)
- 검증 범위: 페르소나 선택·선택 상태·소개글·태그 표시, 통화 시작 버튼 활성화,
  선택한 `persona_id` 전달, 작은 화면과 큰 글꼴에서의 레이아웃
