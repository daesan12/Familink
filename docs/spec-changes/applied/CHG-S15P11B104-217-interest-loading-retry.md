# 피보호자 관심사 설정의 조회·오류·재시도 동작 확정

- 상태: 승인·반영 완료
- 제안자: 손수호
- 작성일: 2026-08-01
- 차단 변경: 아니오
- 영향 스펙·계약: `domains/ACCOUNT_AND_PROFILE.md` AC-003, `UI_AND_NAVIGATION.md` 피보호자 관심사 화면·공통 상태 원칙
- 관련 작업: S15P11B104-217

## 기존 내용

`docs/specs/domains/ACCOUNT_AND_PROFILE.md`의 「확정된 동작」 5~6번과
AC-003은 피보호자 관심사를 0~10개로 전체 교체하고 본인이 저장할 수 있다고
규정한다. 그러나 관심사 편집 화면에 들어갈 때 서버 값을 언제 조회하는지,
조회 중 편집을 허용하는지, 조회 실패 후 어떻게 재시도하는지는 정하지 않는다.

`docs/specs/UI_AND_NAVIGATION.md`의 「공통 상태 화면」은 로딩 중 성공·빈
상태로 단정하지 않고 오류를 빈 상태로 바꾸지 말라고 규정한다. 같은 문서는
일반적인 오류 문구와 재시도 동작을 미결정 사항으로 남기고 있어 J-3p·J-4
관심사 설정 화면의 구체 동작을 공식 구현 기준으로 사용할 수 없다.

현재 `frontend/src/features/profile/screens/CareReceiverMyPageScreen.tsx`는
마이페이지 프로필의 로컬 관심사를 즉시 편집 화면에 전달하고, 저장 시에도
서버 요청 없이 로컬 상태만 바꾼다. 따라서 오래된 값이나 fixture를 최신 서버
값으로 오인해 전체 교체 저장할 수 있다.

## 제안 내용

피보호자 마이페이지의 관심사 설정 화면에 다음 동작을 확정한다.

1. 관심사 설정에 진입하면 현재 그룹의 `groupId`와 본인의 `memberId`로
   `API-INTERESTS-001`을 호출한다.
2. 조회가 끝나기 전에는 관심사 편집 UI를 표시하지 않고 로딩 상태를 표시한다.
   빈 관심사 목록은 조회가 성공했을 때만 정상 결과로 표시한다.
3. 조회가 실패하면 기존 로컬 값이나 fixture를 편집 가능한 서버 값으로 표시하지
   않는다. 오류 안내와 `다시 시도`, `뒤로 가기` 동작을 제공한다.
4. `다시 시도`는 같은 현재 그룹·구성원 식별자로 다시 조회한다. 사용자가 뒤로
   가거나 현재 그룹이 바뀌면 진행 중인 요청 결과를 무효화하고 관심사 하위
   화면을 닫아 이전 그룹의 응답을 반영하지 않는다.
5. 조회 성공 후 저장하면 `API-INTERESTS-002`의 성공 응답에 포함된 정규화
   관심사만 마이페이지 상태에 반영한다. 실패하면 사용자가 편집한 값을 유지하고
   같은 화면에서 다시 저장할 수 있게 한다.
6. 저장 성공 후에는 기존 J-4p 관심사 수정 완료 안내를 표시하고 확인 시 J-1로
   돌아간다. 저장 전 `뒤로 가기`와 `건너뛰기`는 기존 동작대로 변경 내용을
   저장하지 않고 J-1로 돌아간다.

검증 문장:

- 서버 조회가 끝나기 전에는 로컬 관심사나 fixture를 선택된 값으로 편집할 수 없다.
- 조회 실패 후 재시도에 성공하면 서버 관심사로 편집 화면이 열린다.
- 뒤로 가기 또는 그룹 변경 뒤 도착한 이전 요청 결과는 화면 상태를 바꾸지 않는다.
- 저장 실패 시 선택값은 유지되고, 저장 성공 시 서버 응답값이 재진입 후에도 보인다.

## 변경 근거

- S15P11B104-217은 피보호자 마이페이지 관심사의 실제 조회·전체 교체 저장,
  로딩·실패·재시도, 그룹 전환 중 stale 응답 방지를 요구한다.
- 2026-08-01 사용자 결정으로 조회 성공 전 편집을 금지하고, 실패 시
  `다시 시도`와 `뒤로 가기`를 제공하기로 했다.
- 전체 교체 API에서 조회 실패 후 오래된 목록을 저장하면 서버의 최신 관심사를
  의도치 않게 삭제할 수 있으므로 편집 전에 성공한 조회 결과가 필요하다.
- 기존 `frontend/src/features/auth/api/interestApi.ts`에는
  `API-INTERESTS-001~002` gateway와 입력 정규화가 이미 있으므로 API·DB
  계약 변경 없이 화면 상태와 연결할 수 있다.
