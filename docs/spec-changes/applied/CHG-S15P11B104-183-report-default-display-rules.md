# 리포트 기본 노출 및 선택 대상 전환 규칙 명확화

- 상태: 제안
- 제안자: 홍유라
- 작성일: 2026-07-30
- 차단 변경: 아니오
- 영향 스펙·계약: `docs/specs/domains/REPORTS.md`, `docs/specs/domains/UI_AND_NAVIGATION.md`, `docs/specs/contracts/API.md`
- 관련 작업: `S15P11B104-183`, `S15P11B104-158`, `S15P11B104-123`

## 기존 내용

- 리포트 캘린더와 날짜별 일간·건별 리포트 조회 계약은 정의되어 있다.
- 일간 리포트의 `guardianMessageSummary`와 건별 리포트의 `guardianMessage`는 nullable 문자열로 정의되어 있다.
- 보호자 그룹 안에서 피보호자를 스와이프로 전환한다는 내비게이션 원칙은 정의되어 있다.
- 다음 항목은 공식 스펙에 명시되어 있지 않다.
  - 리포트 탭 진입 시 상단 일간 리포트의 기본 선택 날짜
  - 당일 일간 리포트 생성 전 최신 일간 리포트와 당일 건별 리포트를 함께 표시하는 방법
  - 일간 `guardianMessageSummary` 또는 건별 `guardianMessage`가 null일 때 메시지 영역을 렌더링하는지 여부
  - 피보호자 수와 페이지 인디케이터 점 개수의 관계

## 제안 내용

1. 리포트 탭의 상단 일간 리포트에는 생성이 완료된 가장 최신 일간 리포트를 표시하고 해당 리포트의 생성 날짜를 함께 노출한다.
2. 당일 일간 리포트가 아직 생성되지 않은 시각에는 직전의 최신 일간 리포트를 상단에 유지하고, 하단 건별 리포트에는 당일 생성된 건을 시간순으로 표시한다.
3. 당일 통화가 한 건도 없더라도 생성이 완료된 일간 리포트가 하나 이상 있으면 가장 최신 일간 리포트를 상단에 유지하고, 건별 리포트 목록만 빈 상태로 표시한다.
4. 서비스 사용 첫날처럼 건별 리포트는 있으나 생성 완료된 일간 리포트가 전혀 없으면 상단에 일간 리포트 준비 상태를 표시한다.
5. 일간 리포트의 `guardianMessageSummary` 또는 건별 리포트의 `guardianMessage`가 null이면 제목, 배경, 여백을 포함한 전달 메시지 영역 전체를 렌더링하지 않는다.
6. 보호자 그룹에 속한 피보호자 수만큼 화면 하단에 페이지 인디케이터 점을 표시하고, 좌우 스와이프로 피보호자별 리포트 화면을 전환한다.
7. 피보호자 전환은 같은 보호자 그룹 안에서 조회 대상을 바꾸는 동작이며, 그룹 또는 사용자 역할을 변경하지 않는다.
8. `S15P11B104-183`에서는 헤더의 캘린더 아이콘만 화면 구성에 포함하고, 캘린더를 여는 상호작용과 날짜 조회·선택 화면은 원본 Story `S15P11B104-158`에서 구현한다.

## 변경 근거

- `S15P11B104-183` 구현 협의에서 사용자가 직접 리포트 상태별 동작과 피보호자 전환 의미를 설명했다.
- `S15P11B104-183`과 `S15P11B104-158`의 Jira 설명에 캘린더 화면 구현이 중복 기재되어 있어, 사용자가 캘린더 화면을 `S15P11B104-158` 범위로 분리하기로 결정했다.
- Figma `와이어프레임 1.5차 최종`의 다음 노드에서 상태별 화면 구성을 확인했다.
  - 일간·건별 리포트 없음: `220:81`
  - 건별 리포트만 존재: `988:213`
  - 일간·건별 리포트 존재: `170:349`, `220:31`
  - 건별 리포트 상세: `366:153`
- 일간 리포트는 정해진 생성 시각 이후 제공되므로, 당일 건별 리포트와 최신 일간 리포트의 기준 날짜가 다를 수 있다.

## 확인된 영향

- 영향 도메인: 리포트
- 영향 계약: 기존 달력·날짜별 일간·건별 조회 API 조합으로 구현 가능하며 현재 확인된 필드 변경은 없다.
- 영향 화면: 리포트 기본 화면, 일간 리포트 카드, 건별 리포트 목록·상세, 피보호자 전환 인디케이터
- 검증 범위:
  - 일간·건별 리포트가 모두 없는 상태
  - 건별 리포트만 있고 일간 리포트가 없는 상태
  - 최신 일간 리포트와 당일 건별 리포트의 날짜가 다른 상태
  - 당일 건별 리포트가 없고 이전 날짜의 최신 일간 리포트만 있는 상태
  - 전달 메시지가 있는 상태와 null인 상태
  - 피보호자 1명 및 2명 이상인 상태
  - 캘린더 아이콘 표시와 선택 대상 전환

## 확인이 필요한 질문

- 없음. 페이지 인디케이터 점은 현재 위치 표시 전용으로 확정했다.
