# AI 통화 자식 페르소나 표시명 변경

- 상태: 승인·반영 완료
- 제안자: Codex
- 작성일: 2026-07-29
- 차단 변경: 아니오
- 영향 스펙·계약: `AI_CALL`
- 관련 작업: `S15P11B104-137`

## 기존 내용

직전 승인·반영된
`CHG-S15P11B104-137-ai-call-personas.md`에 따라
`docs/specs/domains/AI_CALL.md`의 고정 페르소나 매핑은 `persona_id=1`의
표시명을 `남자 자식`, `persona_id=2`의 표시명을 `여자 자식`으로 정한
상태였다.

## 제안 내용

- `persona_id=1`의 표시명을 `사랑스러운 아들`로 변경한다.
- `persona_id=2`의 표시명을 `사랑스러운 딸`로 변경한다.
- 두 페르소나의 ID, OpenAI 음성, 성별 기반 `엄마/아빠` 호칭, 존댓말,
  성격과 예시 발화는 변경하지 않는다.
- Spring Boot 카탈로그, AI 통화 Web UI, 테스트와 관련 기술 문서의 표시명을
  동일하게 변경한다.

## 변경 근거

사용자가 2026-07-29에 자식 페르소나의 사용자 노출 명칭을 관계 성별 중심의
`남자 자식`, `여자 자식`에서 더 자연스러운 `사랑스러운 아들`,
`사랑스러운 딸`로 변경해 달라고 요청했다.

## 확인된 영향

- 영향 도메인: AI 통화
- 영향 계약: `persona_id` 범위와 공개 API는 유지되며 ID 1·2의 표시명만 변경
- 영향 화면: AI 전화 페르소나 선택 카드와 통화 상대 표시명
- 검증 범위: 서버·Web UI·프롬프트·문서의 ID 1·2 표시명 일치
