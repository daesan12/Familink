# 일정 시간 설정 토글·현재 시각 기준 기본 시간 제안

- 상태: 승인·반영 완료
- 제안자: 홍유라
- 작성일: 2026-07-30
- 차단 변경: 아니오
- 영향 스펙·계약: `docs/specs/domains/CALENDAR.md`
- 관련 작업: `S15P11B104-181`

## 기존 내용

`docs/specs/domains/CALENDAR.md` 「확정된 동작」 12~13항은 일정 등록·수정
화면에 "하루종일" 토글을 제공하고, 시간 설정을 켤 때 시작 08:00·종료
09:00을 사용자 표시 시간대 기준 기본값으로 사용한다.

같은 변경을 반영한
`docs/spec-changes/applied/CHG-20260730-rudgh8182-calendar-allday-reminder-defaults.md`
「제안 내용」 5항도 시간 설정을 켤 때 UI 기본값을 08:00~09:00으로
확정했다. 다만 하루종일 토글의 최초 기본 상태는 미결정으로 남아 있다.

## 제안 내용

1. 일정 등록 화면은 "하루종일" 대신 "시간 설정" 토글을 제공한다.
2. "시간 설정" 토글의 최초 기본 상태는 꺼짐이며, 이 상태는
   하루종일(날짜) 일정이다. 클라이언트는 `startAt`, `endAt`을 보내지 않거나
   null로 보낸다.
3. 사용자가 "시간 설정"을 켜는 순간의 사용자 표시 시간대 현재 시각에서
   분·초를 버려 시작 시각을 정하고, 종료 시각은 시작 시각의 1시간 뒤로
   설정한다.
4. 예를 들어 현재 시각이 05:42이면 시작 05:00, 종료 06:00을 기본값으로
   표시한다.
5. 사용자는 토글을 켠 뒤 시작·종료 시각을 직접 변경할 수 있으며,
   종료 시각이 시작 시각보다 빠르지 않아야 한다는 기존 검증 규칙은
   유지한다.
6. 기본 종료 시각이 다음 날로 넘어가면 다음 날 00:00을 사용하지 않고
   같은 날 23:59로 제한한다. 예를 들어 23:42에 시간 설정을 켜면
   시작 23:00, 종료 23:59를 기본값으로 표시한다.

API 필드, 날짜·시간 일정의 저장 의미와 DB 구조는 변경하지 않는다.

## 변경 근거

- 2026-07-30 사용자가 `S15P11B104-181` 구현 계획을 검토하면서 새 일정은
  기본적으로 하루종일 일정이어야 하고, 시간 설정을 켤 때 고정
  08:00~09:00이 아니라 토글을 켠 현재 시각의 정시부터 1시간을 기본값으로
  사용하도록 결정했다.
- 사용자는 05:42에 시간 설정을 켜면 05:00~06:00이 되는 예시와
  "시간 설정" 토글 표현을 확인했다.
- 사용자는 종료 기본값이 다음 날로 넘어가는 경우 같은 날 안으로
  제한하도록 추가 확인했다.

## 확인된 영향

- 영향 도메인: 일정·캘린더
- 영향 계약: 없음. `API-CALENDAR-003`·`004`의 `startAt`·`endAt`
  전송 규칙은 유지된다.
- 영향 화면: 일정 추가·수정 화면(`E-3`)의 토글 레이블, 최초 상태와
  시간 기본값
- 검증 범위: 토글 최초 상태, 토글 활성화 시 현재 시각 내림, 종료 시각
  1시간 계산과 23:59 상한, 날짜·시간 검증, 하루종일 전환 시 시각 미전송
