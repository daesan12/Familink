# 공유 일정 편집 권한을 활성 그룹 구성원 전체로 확대

- 상태: 승인·반영
- 제안자: 이종철
- 작성일: 2026-08-07
- 차단 변경: 예
- 영향 스펙·계약: `CALENDAR`, `API-CALENDAR-004`, `UI_AND_NAVIGATION`의 `E-2p`
- 관련 작업: `S15P11B104-344`

## 기존 내용

- `docs/specs/domains/CALENDAR.md`의 「확정된 동작」, 「예외」, 「구현 규칙」과
  「인수 조건」은 일정 작성자 또는 그룹 관리자만 일정을 수정·삭제할 수 있다고
  정한다.
- `docs/specs/contracts/API.md`의 `API-CALENDAR-004`와 `API-CALENDAR-005`는
  수정과 삭제를 모두 작성자 또는 그룹 관리자에게만 허용한다.
- `docs/specs/UI_AND_NAVIGATION.md`의 `E-2p`는 작성자 또는 그룹 관리자에게만
  수정·삭제 진입점을 제공한다.

## 제안 내용

1. 해당 일정이 속한 그룹의 모든 활성 구성원은 작성자·참여자·관리자 여부와
   관계없이 일정을 수정할 수 있다.
2. 수정은 제목, 설명, 날짜·시간과 참여자 전체 갱신에 적용한다.
3. 수정해도 원래 작성자는 유지하고 최종 수정자만 실제 수정 구성원으로 갱신한다.
4. 일정 삭제는 기존과 같이 작성자 또는 그룹 관리자만 할 수 있다.
5. 일정 상세에는 작성자를 계속 표시하되 생성·수정 화면에는 작성자를 표시하지
   않는다.
6. 일반 활성 구성원의 일정 상세에는 수정 진입점만 표시하고 삭제 진입점은
   표시하지 않는다.

## 변경 근거

- 사용자 결정: `S15P11B104-344`에서 같은 그룹 구성원의 공동 수정을 허용하되
  공동 삭제는 범위에 포함하지 않는다.
- 현재 백엔드는 수정과 삭제에 같은 작성자·관리자 검사를 사용하며, 모바일도
  하나의 관리 가능 조건으로 수정·삭제 버튼을 함께 노출한다.
- `API-CALENDAR-004`의 요청·응답 구조와 일정의 작성자·최종 수정자 데이터 모델은
  이미 공동 수정에 필요한 정보를 제공하므로 권한 정책만 분리하면 된다.

## 확인된 영향

- 영향 도메인: 공유 일정 수정·삭제 권한
- 영향 계약: `API-CALENDAR-004` 권한 확대, `API-CALENDAR-005` 권한 유지
- 영향 화면: 캘린더 일정 상세 `E-2p`의 수정·삭제 버튼 노출
- 검증 범위: 일반 활성 구성원 수정, 작성자 보존, 최종 수정자 갱신, 작성자·관리자
  삭제, 비활성·다른 그룹 구성원 차단, 작성자 표시 회귀
