## 기존 내용

`docs/specs/domains/ACCOUNT_AND_PROFILE.md`는 회원가입에 로그인 ID와 비밀번호를
입력한다고 정의하지만 허용 문자 조합은 명시하지 않는다. 현재 프런트엔드 구현은
`frontend/src/features/auth/validation.ts`에서 두 항목 모두 영문만 허용한다.

## 제안 내용

- 로그인 ID는 영문 대·소문자와 숫자를 허용하며 길이는 5~15자로 유지한다.
- 비밀번호는 영문 대·소문자와 숫자를 허용하며 길이는 8~16자로 유지한다.
- 한글, 공백, 특수문자는 두 항목 모두 허용하지 않는다.
- 영문과 숫자를 반드시 혼합해야 하는 규칙은 두지 않는다.

## 변경 근거

2026-07-29 사용자 요청으로 로그인 ID와 비밀번호에 숫자를 추가로 허용하기로 했다.
