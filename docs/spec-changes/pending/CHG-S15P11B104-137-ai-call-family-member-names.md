# AI 통화 가족 구성원 실제 이름과 호칭 분리

## 기존 내용

`docs/specs/domains/AI_CALL.md`의 확정 동작 8은 통화 시작 프롬프트에
현재 그룹의 가족 구성원 호칭을 주입하도록 정한다. 현재 구현과
`AI_CALL_PLAN.md`의 가족 구성원 표시명 계약은 모델에 세션 전용
`personKey`와 별칭 우선 `displayName`만 제공하므로, 별칭이 `딸`이나
`손자`처럼 호칭만 담고 있으면 모델이 구성원의 실제 이름을 알 수 없다.

## 제안 내용

Spring Boot가 AI 통화 시작 프롬프트에 주입하는 가족 구성원 컨텍스트를
다음 세 필드로 구성한다.

- `personKey`: DB 구성원 ID를 노출하지 않는 세션 전용 식별자
- `name`: `users.name`에 저장된 구성원의 실제 이름
- `displayName`: 피보호자가 설정한 `member_aliases.alias`; 별칭이 없으면
  `name`과 같은 실제 이름

개발용 `AICALL` fixture의 민지와 준호 별칭은 각각 `딸`, `손자`로 저장해
실제 이름과 호칭의 의미를 분리한다.

## 변경 근거

사용자가 2026-07-29에 가족 구성원의 실제 이름과 호칭을 모델이 구분할 수
있도록 `personKey`, `name`, `displayName`을 함께 제공하고, 개발 fixture의
합성 별칭 `민지 딸`, `준호 손자`를 `딸`, `손자`로 정정하도록 요청했다.
