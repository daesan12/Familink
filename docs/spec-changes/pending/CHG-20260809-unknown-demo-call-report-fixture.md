## 기존 내용

`docs/specs/domains/REPORTS.md`의 확정된 동작 1과 AC-001은 완료되고 전사가
확정된 통화마다 Spring Boot가 Gemini를 호출해 건별 리포트를 생성하도록
정의한다.

## 제안 내용

스토어 배포 전 시연 기간에는 로그인 ID `demoyounghee810`인 피보호자의 건별
리포트를 생성할 때 Gemini 호출 대신 사전에 승인한 고정 분석 결과를 사용한다.
고정 결과도 실제 `call_session_id`에 연결해 저장하며, 실제 통화 시작·종료 시각,
전사 무결성 검사, generation request claim, 중복 방지, 알림과 일일 리포트 입력
흐름은 기존 동작을 유지한다. 그 밖의 계정은 기존 Gemini 분석을 사용한다.

## 변경 근거

- 사용자 결정(2026-08-09): 시연 중 생성형 AI 응답 편차와 외부 호출 실패를
  제거하기 위해 영희 시연 계정의 건별 통화 요약과 보호자 전달 메시지를 고정한다.
- `backend/src/main/java/com/ssafy/s15p11b104/domain/call/report/CallReportGenerationService.java`는
  실제 통화 세션을 유지한 채 분석 결과만 선택할 수 있는 경계를 제공한다.
- `call_reports.summary`의 최대 길이는 100자이므로 고정 요약은 이 제한 안에서
  작성한다.
