# AI 통화 시작 시 최근 통화 요약 맥락 주입

- 상태: 제안
- 제안자: Codex
- 작성일: 2026-07-28
- 차단 변경: 아니오
- 영향 스펙·계약: `AI_CALL`, `COVERAGE`
- 관련 작업: `S15P11B104-137`

## 기존 내용

`docs/specs/domains/AI_CALL.md`의 확정 동작 8은 현재 그룹의 피보호자 관심사,
가족 구성원 호칭과 당일 게시글 분석 결과를 통화 시작 프롬프트에 주입하도록
정한다. 최근 통화의 `call_reports.summary`를 다음 통화의 초기 맥락으로
사용하는 동작은 명시하지 않는다.

## 제안 내용

Spring Boot가 AI 통화를 초기화할 때 같은 피보호자의 가장 최근
`call_reports.summary` 한 건과 해당 통화 종료일을 참고 데이터로 프롬프트에
주입한다.

- 현재 그룹과 현재 피보호자 범위에서만 조회한다.
- 감정 분류와 보호자 전달 메시지는 주입하지 않는다.
- 리포트가 없으면 최근 통화 요약이 없음을 명시한다.
- 과거 요약을 현재 상태로 단정하지 않고, 현재 사용자 발화와 다르면 확인한 뒤
  현재 발화를 우선한다.
- 이번 작업은 새 통화 리포트 생성 파이프라인을 추가하지 않는다.

## 변경 근거

사용자가 승인한 `S15P11B104-137` 구현 계획에서 이전 통화와 자연스럽게 이어지는
대화를 위해 최근 통화 요약을 초기 시스템 프롬프트의 네 번째 동적 컨텍스트로
추가했다.

## 확인된 영향

- 영향 도메인: AI 통화
- 영향 계약: `call_reports` 읽기 범위만 추가하며 공개 API와 DB 스키마는 변경 없음
- 영향 화면: 없음
- 검증 범위: 그룹·피보호자 격리, 최신 리포트 선택, 리포트 부재 처리
