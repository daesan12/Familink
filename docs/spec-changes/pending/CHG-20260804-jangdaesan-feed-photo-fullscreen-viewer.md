# 피드 사진 전체보기 제공

- 상태: 제안
- 제안자: 장대산
- 작성일: 2026-08-04
- 차단 변경: 아니오
- 영향 스펙·계약: `FEED-003`, `UI-026`
- 관련 작업: 게시글 미디어 사용성 개선

## 기존 내용

`docs/specs/domains/FEED_AND_MEDIA.md`의 `FEED-003`은 피드 카드에서 사진을 가로 스와이프로 탐색하도록 정하지만, 사진을 눌렀을 때의 동작과 전체보기 화면은 정의하지 않는다.

## 제안 내용

- 피드와 게시글 상세의 사진을 누르면 검은 배경의 전체화면 사진 뷰어를 연다.
- 사진이 여러 장이면 좌우 스와이프로 이동하고 현재 위치와 전체 개수를 표시한다.
- 닫기 버튼 또는 Android 시스템 뒤로 가기로 기존 화면에 복귀한다.
- 영상의 기존 인라인 재생 동작은 변경하지 않는다.
- 확대·축소 제스처는 후속 요구가 생기기 전까지 제공하지 않는다.

## 변경 근거

- 사용자가 2026-08-04 피드 사진을 눌러 크게 볼 수 있는 동작을 명시적으로 요청했다.
- 작은 피드 카드만으로 사진 세부 내용을 확인하기 어렵다.
- 기존 API와 저장 데이터 계약을 변경하지 않고 클라이언트 화면 동작만 추가할 수 있다.

## 확인된 영향

- 영향 도메인: 가족 피드·소통
- 영향 계약: API·DB 변경 없음
- 영향 화면: 피드, 게시글 상세, 사진 전체보기 모달
- 검증 범위: 사진 열기·닫기, 다중 사진 스와이프, 위치 표시, Android 뒤로 가기, 영상 동작 회귀
