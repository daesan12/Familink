# [CARNATIONS_AND_RANKING] 카네이션 적립·주간 랭킹

> 상태: 일부 확정
> 기준: 2026-07-28, 최신 확정 Notion·요구사항·최신 ERD·API 명세서 2차 수정본

## AI 작업 컨텍스트

- 목적: 가족 피드 참여를 카네이션 잔디와 주간 랭킹으로 보여 주어 지속적인 가족 소통을 돕는다.
- 포함 범위: 게시글 활동에 따른 카네이션 적립, 잔디 조회, 주간 효자 랭킹, 공동 1위와 왕관.
- 제외 범위: 레벨 시스템, 프로필 테두리, 미확정 상세 시각 디자인.
- 핵심 규칙: 보호자가 현재 그룹에 게시글을 한 건 이상 작성한 KST 날짜마다 카네이션을 하나만 적립한다. 주간 경계는 월요일이며 공동 1위를 허용하고, 지난주 1위에게 왕관을 표시한다.
- 완료 조건: 잔디·랭킹 조회 권한과 날짜 집계 규칙이 데이터·API 계약과 일치한다.

## 확정된 동작

1. 보호자의 가족 피드 게시글 작성 활동을 카네이션 잔디로 기록한다.
2. 같은 보호자 구성원이 같은 그룹에서 하루에 여러 게시글을 작성해도 KST 날짜당 카네이션은 하나만 적립한다. 피보호자의 게시글 활동에는 카네이션 잔디를 적립하지 않는다.
3. 게시글이 삭제되어도 이미 적립된 카네이션 기록은 보존한다.
4. 승인된 현재 그룹원은 그룹 잔디와 구성원별 카네이션 기록을 조회할 수 있다.
5. 주간 랭킹은 월요일을 주 시작으로 집계한다.
6. 같은 점수의 공동 1위를 허용하고, 지난주 1위에게 왕관을 표시한다.
7. 레벨 시스템과 프로필 테두리는 제공하지 않는다.
8. 카네이션과 랭킹은 현재 그룹 단위로 조회하며 다른 그룹 활동을 합산하지 않는다. 날짜 범위로 현재·과거 기록을 조회할 수 있다.

확정된 예외:

- 조건: 같은 보호자 구성원이 같은 KST 날짜에 게시글을 여러 건 작성함
  - 처리: 날짜 단위 중복 적립을 만들지 않는다.
- 조건: 공동 1위가 발생함
  - 처리: 공동 1위로 표시하고 각 대상의 왕관 표시를 유지한다.

## 구현 규칙

- 권한: 현재 그룹의 승인된 구성원만 잔디·랭킹을 조회한다.
- 상태와 전이: 보호자 게시글 작성 성공 시 날짜별 카네이션 기록을 중복 없이 만들고, 조회 시 주간 경계에 따라 집계한다. 별도 사용자 적립 API는 없다.
- API:
  - 처리 주체: Spring Boot 일반 그룹 데이터 API
  - Method와 Path: `API-CARNATION-001` `GET /groups/{groupId}/grass`, `API-CARNATION-002` `GET /groups/{groupId}/members/{memberId}/carnations`; 요청·결과는 [`../contracts/API.md`](../contracts/API.md)를 참조한다.
  - 핵심 입력·결과: 그룹 ID 또는 구성원 ID로 잔디·카네이션 기록을 조회한다.
- 데이터:
  - 관련 엔티티: `carnations`, `group_members`, `posts`
  - 읽기·쓰기 소유자: Spring Boot가 게시글·카네이션 흐름과 관련 데이터의 모든 읽기·쓰기를 처리한다.
  - 주요 제약조건: 구성원·적립일 unique, 그룹·적립일 조회 인덱스, 적립일은 KST 기준, 삭제된 게시글과 무관하게 적립 기록 보존
- 화면:
  - 진입점: 보호자 활동 화면 IA `I-5`, 주간 랭킹 IA `H-3p`
  - 사용자에게 표시할 결과: 날짜별 잔디, 주간 랭킹, 공동 1위와 왕관
  - 모바일 화면은 React Native로 구현한다.

## 인수 조건

### AC-001

- Given: 현재 그룹의 보호자가 게시글을 작성한다.
- When: 같은 날짜에 이미 카네이션 기록이 있는지 확인한다.
- Then: 날짜별 중복 없이 잔디 기록을 조회할 수 있다.

### AC-002

- Given: 한 주의 활동 기록과 이전 주 1위가 있다.
- When: 주간 랭킹을 계산한다.
- Then: 월요일 경계를 적용하고 공동 1위를 허용하며 지난주 1위 왕관을 표시한다.

## 미결정 사항

- 카네이션 적립 처리의 트랜잭션 경계와 실패 복구 방식
- 공동 순위와 지난주 왕관의 상세 화면 표현
- 잔디·랭킹 화면의 최종 IA 위치와 상세 UI
