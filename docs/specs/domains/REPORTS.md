# [REPORTS] 통화·일일 리포트

> 상태: 일부 확정
> 기준: 2026-07-27, 최신 확정 Notion·요구사항·AI 리포트 결정·API 명세서 2차 수정본·최신 ERD

## AI 작업 컨텍스트

- 목적: 통화 종료 후 보호자가 핵심 근황을 확인하고, 하루의 여러 통화를 한 번에 이해할 수 있는 리포트를 제공한다.
- 포함 범위: 건별 리포트, 일일 리포트, 감정 대·세부분류, 보호자 전달 메시지, 22시 생성과 조회.
- 제외 범위: 통화 원본·전체 전문, 건별 감정의 보호자 화면 노출, 리포트 재생성, 피보호자 네컷만화(MVP 제외).
- 핵심 규칙: 일일 대표 감정과 세부분류는 여러 통화의 건별 요약을 모아 LLM이 전체 맥락으로 판단한다.
- 완료 조건: 건별·일일 저장과 조회가 API·ERD 계약을 따르고 미결정 매핑을 임의 확정하지 않는다.

## 확정된 동작

1. `COMPLETED` 통화가 끝나면 FastAPI가 `Gemini 3.5 Flash`를 사용해 비동기로 최대 100자 건별 요약, 감정 대분류·세부분류, nullable 보호자 전달 메시지를 생성해 저장한다.
2. `INCOMPLETE` 통화는 transcript가 충분할 때만 건별 리포트를 생성한다. `CANCELLED`·`FAILED`는 생성하지 않는다.
3. 같은 통화의 건별 리포트가 이미 있으면 재생성하지 않는다.
4. 건별 감정은 저장하고 일일 집계에 사용하지만 건별 리포트 화면에는 표시하지 않는다.
5. FastAPI는 매일 `Asia/Seoul` 22시에 당일 건별 리포트를 조회하고 `Gemini 3.5 Flash`를 사용해 피보호자별 최대 200자 일일 요약을 생성·저장한다.
6. 일일 리포트의 대표 감정과 세부분류는 당일 여러 건의 요약 내용을 모두 모아 LLM이 전체 맥락으로 선정한다.
7. 일일 리포트에는 건별 보호자 전달 메시지를 배열 형태로 제공한다. 전달 메시지가 없으면 빈 배열이 될 수 있다.
8. 당일 통화가 없으면 일일 리포트 행을 만들지 않는다. 같은 날짜의 일일 리포트는 재생성하지 않는다.
9. Spring Boot는 저장된 리포트를 조회해 보호자 화면에 제공한다. 보호자는 피보호자별·날짜별로 리포트를 조회한다.
10. 보호자는 리포트 화면을 좌측으로 넘겨 다음 피보호자로 전환하며 별도 구성원 필터를 사용하지 않는다.
11. 보호자 화면에는 최대 100자 건별 요약, 최대 200자 일일 요약, 대표 감정 표시와 세부분류 텍스트, 보호자 전달 메시지를 제공한다. 전체 통화 전문은 제공하지 않는다.
12. 건별 보호자 전달 메시지는 통화 종료 후 리포트 생성 단계에서 함께 만들며 통화 중 Tool Calling으로 처리하지 않는다.
13. FastAPI는 건별·일일 리포트를 DB에 직접 기록하고 Spring Boot에 생성 완료 콜백을 보내지 않는다.

건별 감정 대분류 enum은 `ANGER`, `SADNESS`, `ANXIETY`, `HURT`, `EMBARRASSMENT`, `JOY`, `NEUTRAL`이다. 한국어 표시명과 이모지는 별도 미결정 사항을 따른다.

확정된 예외:

- 조건: 당일 통화가 없음
  - 처리: 일일 리포트 행을 생성하지 않고 조회 화면은 빈 상태를 표시한다.
- 조건: 건별 리포트가 아직 준비되지 않음
  - 처리: API 계약에 따라 준비되지 않은 상태를 표시한다.
- 조건: 같은 통화 또는 같은 피보호자·날짜의 리포트가 이미 존재함
  - 처리: 기존 건별 또는 일일 리포트를 재생성하지 않는다.

## 구현 규칙

- 권한: 리포트는 보호자만 조회한다. 현재 그룹과 선택한 피보호자 범위를 확인한다.
- 상태와 전이: 통화 종료 후 건별 리포트가 비동기로 생성되고, 22시 작업이 저장된 건별 리포트를 집계한다. 재생성은 하지 않는다.
- API:
  - 처리 주체: FastAPI 생성·저장, Spring Boot 조회
  - Method와 Path: `API-REPORTS-001` `GET /groups/{groupId}/care-receivers/{memberId}/reports/calendar`, `API-REPORTS-002` `GET /groups/{groupId}/members/{memberId}/reports/daily/{reportDate}`, `API-REPORTS-003` `GET /call-sessions/{callSessionId}/report`; 요청·결과·명시 오류는 [`../contracts/API.md`](../contracts/API.md)를 참조한다.
  - 핵심 입력·결과: 그룹·피보호자·리포트 날짜 또는 통화 세션 ID로 저장된 리포트를 조회한다.
- 데이터:
  - 관련 엔티티: `call_reports`, `daily_reports`, `call_sessions`, `call_transcripts`
  - 읽기·쓰기 소유자: FastAPI가 `call_reports`·`daily_reports`를 직접 저장하고 Spring Boot가 조회한다.
  - 주요 제약조건: 건별 summary 최대 100자, 일일 summary 최대 200자; 감정 enum은 위 7개 값이며 세부분류 필드의 정확한 길이·매핑은 아래 미결정 사항을 따른다.
- 화면:
  - 진입점: 보호자 하단 `일일 리포트` 탭, IA `G-1`~`G-3`, 좌측 넘김으로 다음 피보호자 전환
  - 사용자에게 표시할 결과: 빈 상태 또는 날짜별 요약·전달 메시지·건별 요약

## 인수 조건

### AC-001

- Given: 통화가 `COMPLETED`이고 아직 건별 리포트가 없다.
- When: 통화가 종료된다.
- Then: FastAPI가 최대 100자 건별 summary와 감정·보호자 전달 메시지를 저장한다.

### AC-002

- Given: 같은 날짜에 피보호자의 건별 리포트가 여러 개 있다.
- When: `Asia/Seoul` 22시 일일 작업이 실행된다.
- Then: 모든 건별 요약을 LLM에 모아 대표 감정과 세부분류를 한 번 판단하고 최대 200자 일일 리포트를 저장한다.

### AC-003

- Given: 당일 통화가 없다.
- When: 일일 리포트를 조회한다.
- Then: 리포트 행이 없고 화면은 빈 상태를 표시한다.

## 미결정 사항

- 22시 이후 종료된 통화를 어느 날짜의 일일 리포트에 포함할지
- `daily_reports.guardian_message` 단일 필드와 API의 `guardianMessages` 배열 매핑
- 감정 세부분류 허용 목록·중립값·표시 이모지
- 세부분류 길이의 API/ERD 50자와 기존 설계 30자 충돌
- `INCOMPLETE` 통화의 transcript 충분 여부를 판정하는 기준
